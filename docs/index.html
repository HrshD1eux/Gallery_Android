FAQ

Frequently Asked Questions

Direct answers to common questions about Imava.

Is Imava completely offline? Does it upload anything to the cloud?

Yes, Imava is 100% offline. Not a single photo, video, tag, or telemetry byte ever leaves your device. The only optional network socket check is to notify you of new GitHub release APKs.

How does the Hidden Vault encryption work?

Media moved to the vault is encrypted at rest using AES-256-GCM via the AndroidKeyStore hardware module (TEE/StrongBox). Encryption keys are protected by PBKDF2 with 250,000 iterations and 16-byte cryptographic salts.

What is the Decoy PIN mode?

Decoy PIN provides plausible deniability. If someone compels you to unlock your vault, entering your alternate Decoy PIN silently opens a fake, empty gallery instead of your real vault.

How do I back up my encrypted vault?

Go to Vault Security Settings and tap "Export Backup 💾". This packages all encrypted ciphertexts and metadata into a standalone .imava container encrypted with a custom passphrase that can be restored on any device.

Does Imava work on de-Googled custom ROMs?

Yes! Imava has zero dependencies on Google Play Services or Firebase and runs natively on GrapheneOS, CalyxOS, LineageOS, and vanilla AOSP.
